# AyaEX 2026.11.2

The builds of AyaEX release 2026.11.2. They go with
[AyaEX-MercuryCore](https://github.com/AyaEX-PUBLIC/AyaEX-MercuryCore/tree/2026.11.2)
and [AyaEX-MercuryRCC](https://github.com/AyaEX-PUBLIC/AyaEX-MercuryRCC/tree/2026.11.2)
at the same tag.

| File | Build |
| --- | --- |
| `AyaEX-Web-2026.11.2.tar.gz` | The web app from 2026-11-23, with the engine fixes below, better graphics in the browser (anti-aliasing, SSAO, glow, more normal maps, 2014 blob shadows), an option to turn off stencil shadows in 2010-2013, and the 2016 loading screen's textures with the game's name and owner. |
| `AyaEX-Server-linux-x64-2026.11.2.tar.gz` | `Aya.Server` built on 2026-11-27, with the same engine fixes and a chat filter the site can set for gameservers. |
| `AyaEX-Server-linux-arm64-2026.11.2.tar.gz` | New: the same `Aya.Server` for 64-bit Arm Linux, built from the same source. |
| `AyaEX-WiiU-2026.11.2.wuhb` | The same Wii U app as 2026.11.0. |
| `AyaEX-Switch-2026.11.2.nro` | The same Switch app as 2026.11.0. |

Engine fixes:

- Legacy terrain is no longer black in places: its lighting reads the whole terrain.
- Switching client versions mid-game no longer freezes or crashes: game scripts don't get the engine's locked CoreGui objects, chat and `string.rep` can't loop endlessly, and in the browser a runaway script times out instead of freezing the tab.
- Big places run smoother: cheaper text, network bursts spread over frames, and one animator step per frame.
- Places saved as binary files keep `IntValue` an Int and read and write Int64 values like Roblox, so 2016 Studio opens them.

Install notes are in the [README](https://github.com/AyaEX-PUBLIC/AyaEX#readme).
