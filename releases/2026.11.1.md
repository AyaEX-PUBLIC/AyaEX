# AyaEX 2026.11.1

The builds of AyaEX release 2026.11.1. They go with
[AyaEX-MercuryCore](https://github.com/AyaEX-PUBLIC/AyaEX-MercuryCore/tree/2026.11.1)
and [AyaEX-MercuryRCC](https://github.com/AyaEX-PUBLIC/AyaEX-MercuryRCC/tree/2026.11.1)
at the same tag.

| File | Build |
| --- | --- |
| `AyaEX-Web-2026.11.1.tar.gz` | The web app from 2026-11-12, with the engine fixes below, Team Create in Studio on Mercury sites, an AI Agent in Studio for coding agents over MCP, and a calmer loading screen and Start page. |
| `AyaEX-Server-linux-x64-2026.11.1.tar.gz` | `Aya.Server` built on 2026-11-10, with the same engine fixes and Team Create edit servers. |
| `AyaEX-WiiU-2026.11.1.wuhb` | The same Wii U app as 2026.11.0. |
| `AyaEX-Switch-2026.11.1.nro` | The same Switch app as 2026.11.0. |

Engine fixes:

- TweenService steps tweens safely, and `TweenInfo.new` takes all its arguments.
- Animator calls work on a Humanoid without a parent.
- Unions from 2017 and 2018 load (CSGPHS physics data versions 4 and 5).
- `ScreenGui.Enabled = false` hides the GUI and stops its input.
- Text is drawn and measured at its `TextSize`.
- `GuiObject.AnchorPoint` is supported.
- `BindToRenderStep` functions get the frame's step.
- Setting `Velocity` on a part at rest isn't thrown away.
- A script setting `Size` resizes a part in place.

Install notes are in the [README](https://github.com/AyaEX-PUBLIC/AyaEX#readme).
