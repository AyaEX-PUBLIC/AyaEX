# AyaEX 2026.11.0

The first public release of the AyaEX builds. They are the builds of AyaEX
release 2026.11.0.

| File | Build |
| --- | --- |
| `AyaEX-Web-2026.11.0.tar.gz` | The web app on the stable client channel since 2026-11-07. It has the R15 body and hand colour fixes, "AyaEX" in the page title with a tab icon, "AyaEX Studio", and the price of a new game shown in Studio's Publish dialog. |
| `AyaEX-Server-linux-x64-2026.11.0.tar.gz` | `Aya.Server` built on 2026-11-07, with the R15 renders and the R6 accessory attachments fixed |
| `AyaEX-WiiU-2026.11.0.wuhb` | The Wii U app from 2026-10-24, with smoother frames and fewer lag spikes |
| `AyaEX-Switch-2026.11.0.nro` | The Switch app from 2026-10-24, with the same frame-pacing work |

Install notes are in the [README](https://github.com/AyaEX-PUBLIC/AyaEX#readme).
